# O-In Store — PRDXQ redesign concept

Independent, uncommissioned design concept. It is not the official website and does not imply endorsement or a business relationship.

## Pages
- [Concept](index.html)
- [Store guide](store.html)

## Design direction
Retail-first visual identity using fresh citrus accents, ivory surfaces, dark typography, restrained glassmorphism and responsive multi-page navigation.

## Research reference
https://www.gateway-gardens.de/en/life/

The workflow at `.github/workflows/pages.yml` deploys this static site to GitHub Pages. First enable Pages in repository Settings → Pages → Build and deployment → Source: GitHub Actions.
